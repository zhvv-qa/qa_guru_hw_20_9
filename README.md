# qa_guru_hw_20_9
Провести рефакторинг своего теста на регистрацию студента по форме https://demoqa.com/automation-practice-form, 
используя инструменты объектно-ориентированной парадигмы для инкапсуляции деталей реализации бизнес-шагов пользователя, 
таким образом реализовав идеи шаблона PageObject.

ЧАСТЬ II (реализовать в бренче high-level-step-objects)

В этой части мы рассматриваем как ценный c точки зрения бизнеса шаг пользователя – «отправить форму с данными» 
или другими словами «провести регистрацию через форму». 
Также шагом считаем подтверждение результата проделанной работы (как например, подтверждение, что регистрация прошла успешно).

Также в этой части следует провести рефакторинг работы с данными пользователя, представив их в виде объекта датакласса, используя уже имеющиеся знания из предыдущих уроков.

Кратко: High-Level Step Objects делают тесты более читаемыми, поддерживаемыми и расширяемыми, скрывая технические детали и концентрируясь на бизнес-логике.
